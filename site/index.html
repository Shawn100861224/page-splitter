图片自动分区

一张照片 → 按题目自动切段 → 导出 ZIP

🔒 图片不上传

把照片拖进来，或点击选择

支持 JPG / PNG / WebP 相机原图 · 也可以直接 Ctrl+V 粘贴截图

它做什么

把一页拍下来的习题，按题目切成若干张单图。自动先切一遍，切不准的地方你拖一下线就行，最后打包成 ZIP 下载。

  1. 选图点上面的方框，或把照片/截图直接拖进来、Ctrl+V 粘贴
  2. 调分界红色横线可拖、点空白处加一条、点 × 删一条，Ctrl+Z 撤销
  3. 导出手机点「保存到相册」直接进图库，电脑上打包 ZIP

适合

  • 横排单栏的手写笔记、习题本
  • 印刷题册、讲义、手机截图
  • 页面上有阴影、桌面入镜、光照不匀

不适合

  • 竖排、双栏、表格（会提示，别硬用）
  • 密排正文（会按行切，一页几十段）
  • 拍得很糊 / 墨很淡（会漏带，需要手动补线）

全程在你的浏览器里算：不上传、无账号、无统计，断网也能用。

你是在微信/QQ 内置浏览器里打开的

这里没有「存到相册」的接口，点任何下载都只会进「文件」。存相册有两条路：

  1. 长按图片 → 保存图片（弹出保存面板后，按住任意一张图）
  2. 点右上角 ⋯ → 在浏览器打开，再点「保存到相册」

    拖动横线调整分界 · 点横线右侧的 × 删除 · 点空白处加一条 · 导出按墨迹左右边界裁，不会截字

      长按图片 → 存到相册

      安卓：长按下面任意一张图 → 「保存图片 / 下载图片」，就会进相册。
      iOS：长按 → 「存储到照片」。
      下面的「下载」按钮是存进「文件」App，不是相册。

      纯前端，零后端：图片不离开本机浏览器，没有账号、没有上传、没有统计。 算法是「二维背景归一化 → 行墨迹剖面 → 间距聚类」，参数由真实手写笔记照片标定。
